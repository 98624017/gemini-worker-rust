# Midjourney V8.2 与 Niji 7 双模型控件规划

日期：2026-10-22。状态：产品方向已由用户确定；本文件是后续开发规划，未实施界面、未改变 API，也未新增生成测试。当前范围替代此前以 V8.1 为产品基线的建议。

参数支持、范围和默认值以官方文档为依据；官方明确的参数直接纳入规划，版本专属定义优先于通用定义。渠道运行记录独立保存，不作为参数控件的启用条件。

## 1. 产品范围

提供两个生成模型入口，用户填写画面描述，界面选项统一编译成提示词末尾的参数：

| 产品模型 | 定位 | 唯一版本选择参数 |
| --- | --- | --- |
| Midjourney V8.2 | 默认主模型，通用摄影、设计、插画等创作 | `--v 8.2` |
| Niji 7 | 动漫与东方插画审美 | `--niji 7` |

V8.2 与 Niji 7 是两个模型家族选择；FAST / RELAX 是独立的渠道速度设置。界面不将“动漫”做成在 `--v 8.2` 上叠加的风格开关。Niji 的版本号不是 8.2，亦不随主模型版本号升级。[版本]、[Niji7]

V8.1 资料作为历史参考保留，首版模型选择器只提供上述两项，不额外维护旧版本切换。这个范围决定只适用于新产品界面，不要求删除代理对既有手写提示词的透传兼容。

## 2. 参数依据与输入角色

Midjourney官方Version页给出V8.1 / V8.2的功能范围；Niji使用官方Niji文档和适用的通用参数定义。各控件附原始来源，官方没有说明的参数不列入对应模型配置。[版本]、[Niji参数]

普通参考图、风格参考和主体编辑分别管理：普通参考图用image数组及iw，风格参考用sref/sw，V8指令编辑用edit。图片上传和预处理沿用项目既有能力。

## 3. 界面结构

基本流程：选择模型 → 填写正文 → 可选参考图 → 设置常用选项 → 生成。文字输入区只承载用户描述，不预填参数后缀；可折叠的“最终提示词”供高级用户查看实际提交内容。

| 区域 | 内容 | 交互规则 |
| --- | --- | --- |
| 模型 | Midjourney V8.2 / Niji 7 | 默认主模型 V8.2；切换时使用对应参数配置，不保留冲突版本参数 |
| 提示词 | 用户的中文或其他文字描述 | 原文保存，不翻译、不因选择动漫模型自动改写为英文或增加任意风格词 |
| 比例 | 1:1、3:2、2:3、4:3、3:4、16:9、9:16 | 默认1:1；这些是产品预设 |
| 速度 | FAST / RELAX | 对应现有两个渠道model |
| 参考图 | 普通内容／构图参考 | 沿用URL数组，本层最多六张 |
| 常用控制 | 风格化、变化度、Raw | 按官方定义提供范围和帮助文字 |
| 高级控制 | 排除元素、seed、模型特有参数 | 只有已进入该模型能力配置的字段会编译提交 |

模型切换时可以保留正文、已上传的普通参考图和共同支持的比例；不兼容的选项提示已重置。各模型的设置可分别记忆，重新切回时恢复其自身配置。参考图角色转换须由用户显式选择，不把普通图片静默变成风格图或主体编辑图。

## 4. 两套参数配置

以下是前端控件配置，不是新增的后端请求字段。表中通用参数使用官方通用数值定义；模型专属范围单独列出，官方未说明的项目直接省略。

| 控件／参数 | Midjourney V8.2 | Niji 7 | 首版处理 |
| --- | --- | --- | --- |
| 版本选择 | `--v 8.2` | `--niji 7` | 每次恰好一个模型选择，二者互斥 |
| 比例 `--ar` | 默认1:1；SD最大14:1，HD最大4:1，含反向 | 默认1:1，整数宽高比 | 首版提供常用比例按钮 |
| 变化度 `--c` | 0–100，默认0 | 0–100，默认0，按官方通用定义 | 滑块＋数值输入 |
| Raw `--raw` | 开关 | 开关；减弱默认动漫倾向 | 自动／开启，省略时沿用账号设置 |
| 风格化 `--s` | 0–1000，默认100 | 0–1000，默认100，按官方通用定义 | 滑块＋数值输入 |
| 普通参考强度 `--iw` | 支持调整普通参考图影响 | 0–2，默认1，官方Niji7专表 | 有普通参考图时显示；按模型分别配置 |
| 排除元素 `--no` | 元素列表 | 元素列表 | 简短标签输入 |
| 种子 `--seed` | 整数0–4294967295，默认随机 | 整数0–4294967295，默认随机，按官方通用定义 | 高级数值输入；默认不发送 |
| 风格参考 `--sref` / `--sw` | 图片或风格代码；sw为0–1000，默认100 | 图片或风格代码；sw按通用定义0–1000，默认100；支持sv4兼容 | 独立风格参考区，不默认附加sv |
| 高清 `--sd` / `--hd` | 标准1024px档／高清2048px档 | — | V8.2提供标准／高清选项 |
| 特异 `--w`、实验 `--exp` | w为0–3000、exp为0–100，默认0 | — | V8.2高级滑块 |
| 无缝纹理 `--tile` | 开关 | — | V8.2高级开关 |
| 指令编辑 `--edit` | 最多四张参考图 | — | 作为独立编辑功能，不混入普通参考图 |
| `--q`、`--stop` | V8.2 不支持 | 不套用旧 Niji / MJ 教程的值 | 首版两者均不开放该控件 |
| `--cref` / `--cw` | 不支持，V8 有 Edit 机制 | Niji7 发布说明明确不支持 cref | 不设置旧角色参考控件，不承诺普通垫图锁定角色 |
| `--oref` / `--ow` | 不支持，属于 MJ V7 Omni | 当前官方Omni兼容范围仅MJ V7，未包括Niji7 | 首版隐藏，主体一致性另行规划 |
| 旧 `--style cute/scenic/expressive` | 不作为V8.2选项 | 不继承旧 Niji 风格枚举 | 如做产品风格预设，明确其由正文或风格参考实现，不伪造旧参数兼容 |

参数范围及支持依据：[版本]、[图像提示]、[Niji7]、[Niji提示]、[Niji参数]、[官方参数研究]。普通参考图权重的官方数值表单列V8.1为0–3、默认1，Niji7为0–2、默认1；V8.2条目仅列官方明确的功能支持，不将V8.1数值改写成V8.2独立定义，也不人为将主模型限制成0–2。

## 5. API 映射和参数拼接

现有下游 model 的语义仍为生成速度：

| 速度 | 当前请求 model | 主模型提示词后缀 | 动漫模型提示词后缀 |
| --- | --- | --- | --- |
| FAST | `mj_fast_imagine` | `--v 8.2` | `--niji 7` |
| RELAX | `mj_relax_imagine` | `--v 8.2` | `--niji 7` |

产品统一用现有model选择速度，用官方版本参数选择生成模型；不新增模型标识。[Niji7]、[当前协议]

前端内部至少区分：模型家族及版本、速度、原始提示词、普通参考图、该模型的结构化参数。由一个编译器生成最终 prompt，保持正文在前、参数在后，别名归一化且每个设置只生成一次。代理继续负责附加唯一 `--fast` 或 `--relax`。[当前协议]

主模型请求示例：

```json
{
  "model": "mj_fast_imagine",
  "prompt": "一只橙色陶瓷狐狸，蓝色针织围巾，奶油色背景，柔和摄影棚灯光 --v 8.2 --ar 3:2 --s 100 --c 0",
  "response_format": "url"
}
```

Niji请求示例：

```json
{
  "model": "mj_fast_imagine",
  "prompt": "一位短发少女站在雨后的车站，蓝色外套，清晰线稿，柔和暮色 --niji 7 --ar 2:3",
  "response_format": "url"
}
```

普通参考图沿用 `image: [URL, ...]`；不把风格图和主体编辑图混入同一数组。当前 API 顶层 `quality`、`size`、`n`、`stream` 仍不能直接使用。以上规划不要求把界面所有状态原样增加为新后端字段。

## 6. 切换与兼容规则

1. 从 V8.2 切到 Niji7 时，不同时发送 `--v` 和 `--niji`；切回亦然。若高级用户手写参数与模型选择冲突，提交前明确提示，不能依赖上游猜测优先级。
2. 切入Niji7时，参考强度限制为官方0–2范围；超限时提示用户并恢复该模型保存值或默认1。
3. 切换模型时只输出对应配置中的参数；Niji7不带V8.2的sd/hd、w/exp、Edit，V8.2不自动继承Niji的sv4选项。
4. 首版只处理一次 Imagine 的文生图／普通参考图，不开放 repeat、permutations、Draft、Turbo、视频或账号隐私开关。
5. 对账号相关开关，区分“自动继承”与“显式开启”；没有已确认的关闭语法时，不发送例如 `--raw false`，也不将省略参数描述为已强制关闭。
6. 历史保存原文、模型家族与版本、速度、结构化选项及最终 prompt；回填时按该模型配置恢复，避免把旧任务重新解释为当前默认版本。

## 7. 建议交付顺序

| 顺序 | 可独立验收的结果 | 完成判据 |
| --- | --- | --- |
| 1. 模型配置与编译器 | 两套官方参数配置、统一prompt拼接 | 范围、默认值、别名及互斥规则集中管理，版本参数只出现一次 |
| 2. 主模型基本界面 | 用户只写正文，通过控件调用V8.2 | 比例、速度和基础参数不会重复；可查看最终prompt；既有直接API调用不改变 |
| 3. 动漫模型与切换 | 用户能切换Niji7并使用对应选项 | 正文保留，模型选择互斥、iw上限正确、特有参数随模型切换 |
| 4. 高级选项 | V8.2高清与两模型风格参考 | 控件完整映射官方语法；普通图、风格图、编辑图分别管理 |

软件验证覆盖参数编译、官方数值边界、默认值、模型切换和请求格式。参数是否纳入界面以官方文档为准。
