# Triage labels

使用工程技能的默认 role 名称作为 GitHub label 名称。

| Role | GitHub label |
| --- | --- |
| needs-triage | needs-triage |
| needs-info | needs-info |
| ready-for-agent | ready-for-agent |
| ready-for-human | ready-for-human |
| wontfix | wontfix |

本次发布仅补建实际需要的 ready-for-agent；其他标签按后续工作需要创建。

ready-for-agent 表示 ticket 已有可执行的范围和验收条件。是否可立即开始，仍由 open blockers 决定。
